## 判据（切换后累计 ≥ 8 条泳道执行再判，不足就继续攒，⛔ 不凭一批三五条下结论）

1. **质量**：失败类占比 ≤ 21%（基线 11% ＋ 10 个百分点的小样本容差）。
2. **归因**：每条 FAIL / NO-SENTINEL 读 `tail -50` 判原因。环境类（529、index.lock、.51 不可达、预算线）不计入模型质量；
   质量类（实现错、评审轮次耗尽、判据理解错）→ 该 opener **类型**以后在【设置】行标 `模型: Opus`，登记进本文件「降级清单」。
3. **成本**：`python3 scripts/token_ledger.py --since <切换日> --compare docs/token治理/baseline-0901-0915.json --out docs/token治理/phase2-check`，
   「泳道/opener」类单会话平均成本 ≤ 基线的 60%（≤ $3.1）。
4. 1 不过 ⇒ 不回退默认值，先看 2 的归因把对应类型标 Opus 后再攒一批；连续两次 1 不过才开会讨论整体方案。
