# 人事部#4 · 新 UI 上线说明与使用需求反馈

## 一、这次界面改了哪里

- **工作台（电脑上打开）**：岗位列表、上传简历、解析结果列表、字段校对、面试题确认、邀约签发这几页都换成了统一的卡片式界面，按钮和表格也统一了；字段校对页里**「待校对」的字段现在会标黄提示**，AI 抽出来的内容旁边能直接看到置信度。
- **手机上**：候选人同意页、面试邀约签发页这两页专门按手机屏幕调过（单列、按钮全宽、字号加大）。

## 二、想请你反馈三件事

**① 新界面用起来顺手吗**：哪个页面、哪个动作不顺手，直接说（比如"上传那步按钮太小""列表里的字看不清"都可以）。

**② 手机上用不用得上**：你日常会不会在手机上处理"邀约签发"这类事？如果会，手机上还缺什么操作？候选人如果反馈过手机页面不好用，也请告诉我是哪一步。

**③ 使用需求**：你日常最花时间的三个动作是什么？如果系统下一步先替你解决其中一个，你希望是哪一个？
