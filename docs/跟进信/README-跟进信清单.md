## 发送状态（起草者唯一可写的值是 `⏳ 待你审`）

| 状态 | 含义 | 怎么变过来 |
|---|---|---|
| `⏳ 待你审` | 草稿态，内容还没审 | 起草者唯一可写 |
| `🆕 待发` | 已批准，等发送 | Shao Peishen 审完手工改写（HR 侧无自动派发） |
| `⏸ 暂缓` | 内容已审、主动不发 | 由 `🆕 待发` 手工改写 |
| `✅ 已推送 <日期>` | 已发出 | 发出后手工改写 |
| `📥 已回件并回灌 <日期>` | 闭环，**串行原则据此放行下一封** | 回件消化完后手工改写 |
| `✅ 无需回复` | 信件不要求对方动作，发出即闭环、不占串行闸 | 只能起草时判定，⛔ 不得事后追认 |
| `📨 已确认闭环 <日期>` | 对方以其它形态响应且我方已明确回复确认 | 须能指出对方响应的落档件 ＋ 我方确认的原话 |
| `❌ 已作废` | 作废 | 手工改写，不占号 |

🔴 **串行原则**：同一收信人同时只能有一封在途。只有最近一封是 `📥` / `✅ 无需回复` / `📨` 时才能起草下一封；`⏳` / `🆕` / `⏸` / `✅ 已推送` 一律不得起草——改在接力文档登记「待前信闭环后发」，⛔ 不要先写出来放着。
