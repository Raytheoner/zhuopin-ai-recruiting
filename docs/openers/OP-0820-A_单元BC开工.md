# ⛔ 已废弃 —— 不要用这份

本文件已被 **`docs/openers/OP-0820-全量编排.md`** 取代，2026-08-19 作废。

**作废原因**：本文件里的 opener ① 写了「Session：利旧即可」「提交本轮 Cowork 会话产出的改动」，
这两句依赖"你正处在出这份 opener 的那个 Cowork 会话之后"这个前提。转场到新 session 后前提失效，
而文件本身不会自己改口——照着跑会找不到"本轮"指的是哪一轮。

取代它的那份里，每条 opener 都是**自包含**的：不引用任何"本轮 / 上一轮 / 上面那个"，
任何一个新开的 CC session 拿到都能独立执行。
