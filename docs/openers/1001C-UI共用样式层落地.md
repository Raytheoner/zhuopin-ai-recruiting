## 零、为什么

`09-UI-Design.md` v1.0（2026-10-07 定稿，Shao Peishen 答 `2a`）规定：**引入极简共用样式表 `app.css`**
（无框架、无构建链、⛔ 不引第三方库、品牌色沿用现有蓝 `#0d6efd`）。现状是 8 页各自内联 `<style>`、
颜色字面量散落（`grep` 到 `#fff3cd`／`#ffe69c`／`#339af0`／`#fd7e14` 等各页重复），
同一控件在不同页会长得不一样。本泳道做 §11 的①：抽共用层并把颜色字面量收敛进去。

## 一、授权与边界

⛔ 只许改/建：

- 新建 `app/web/static/app.css`
- `app/web/static/*.html`：**只加一行 `<link rel="stylesheet" href="app.css">`**（放在 `<!--BASE_HREF-->` 之后），
  以及本 opener §二 明确列出的三页样式收敛

⛔ 不改任何 JS 行为、不改任何页面文案、⛔ 不删任何 AI 标识文案、⛔ 不改后端 `app/web/server.py`、
⛔ 不动 `tests/`（用既有测试当判据）、⛔ 不引第三方依赖。

## 二、交付物

### 1. `app/web/static/app.css`（新）

- `:root` 令牌（与 `09-UI-Design.md` §3 逐字对齐）：`--color-primary:#0d6efd`、`--color-primary-weak:#339af0`、
  `--color-warn-bg:#fff3cd`、`--color-warn-border:#ffe69c`、`--color-warn-fg:#664d03`、
  `--color-accent-reask:#fd7e14`、`--color-text:#212529`、`--color-text-muted:#6c757d`、`--color-border:#dee2e6`。
- 基础排版：`body { font-family: -apple-system, "PingFang SC", sans-serif; color: var(--color-text); }`
  （⛔ 不要覆盖各页已有的 `max-width`／`margin` 布局，除下面点名的三页外不接管页面级布局）。
- 组件类（**类名与现有页面一致，便于逐页替换**）：
  `.notice`（AI 提示条：warn 底/边/字，12px 16px 内边距，8px 圆角）、
  `.badge`（4px 圆角小徽标）、
  `.data-table`（表头加粗、行 hover、单元格内边距、边框 `--color-border`）、
  `.btn` / `.btn-primary` / `.btn-danger`、
  `.field-row` / `.field-row.selected { outline: 2px solid var(--color-primary-weak); }`、
  `mark { background: #ffec99; }`、
  `.pending { background: var(--color-warn-bg); }`、
  `.empty-hint`（空态文案样式）。
- ⛔ 不写 `!important`；⛔ 不写媒体查询以外的复杂选择器；⛔ 不引 `@import`。

### 2. 8 个页面加 `<link>`

`login.html`／`index.html`／`upload.html`／`resume_list.html`／`resume_review.html`／
`interview_invite_issue.html`／`interview_consent.html`／`interview_prep_review.html`
——各在 `<!--BASE_HREF-->` **之后**加一行 `<link rel="stylesheet" href="app.css">`（相对路径，靠 `<base href>` 解析）。

### 3. 三页样式收敛（⛔ 只动这三页的内联样式，不动结构/文案/JS）

- `resume_review.html`：删掉内联 `<style>` 里 `.pending` / `mark` / `#raw-text` / `.field-row` / `.field-row.selected`
  这五条**与 app.css 等价**的规则（`#raw-text` 保留在 app.css 里）；页面其余内联样式与 DOM 一字不动。
  收敛后该文件里不再出现 `#ffec99`、`#339af0`、`#fff3cd` 三个字面量。
- `resume_list.html`：给 `<table>` 加 `class="data-table"`；空态 `<p id="empty-hint">` 加 `class="empty-hint"`
  （文案不动）。文件里不再出现 `border="1"`。
- `upload.html`：只加 `<link>`（若它有等价重复的颜色字面量，就顺手收敛到 app.css；没有就到此为止）。
