## 二、交付物

### 1. `scripts/ui_narrow_check.mjs`

- 起一个**只读静态服务**把页面喂给浏览器：读 `app/web/static/<页>.html`，把 `<!--BASE_HREF-->` 换成
  `<base href="/">`，并把 `/static/*` 映射到 `app/web/static/*`（⛔ 只为测量，不写回任何文件）。
  端口随机（`listen(0)`），跑完关掉。
- 用运行时 node + playwright（`channel: "chrome"`、`headless: true`）对**两页**：
  `interview_consent.html`（候选人同意）与 `interview_invite_issue.html`（邀约签发），
  在 **375×812**（`deviceScaleFactor: 1`，`isMobile: true`）下：
  ① 读 `document.documentElement.scrollWidth` 与 `body.scrollWidth`；
  ② 读主要按钮的 `getBoundingClientRect().width`；
  ③ 截全页图到 `data/eval/ui-narrow/<页>-375.png`；
  ④ 判据：`scrollWidth <= 375`（无横向滚动）；按钮宽度 ≥ 300（移动端全宽）。
- 打印 JSON 摘要（每页 scrollWidth/按钮宽/结论）到 stdout，并以退出码给出总判（全过 0）。
- ⛔ 不联网（页面不引任何外链；若发现外链 ⇒ 记录并跳过）。

### 2. `docs/findings/2026-10-07-UI-375px实测.md`
