# [Mac]0920K opener 完成判据的消费者（机器判据闸）

## 零、为什么

今天两次命中同一个形状：

- `0920H` 治的是「上下文守卫是**提醒型、没有消费者**」——提醒的对象是泳道自己，而泳道正埋头干活。
- `0920I` 暴露的是「**opener 的完成判据也是提醒型、也没有消费者**」：判据只写在正文里靠泳道自觉核对，`run-lanes.sh` 只认哨兵字样 ⇒ 泳道在一条 `grep` 判据实测为 0 的情况下照样打了 `OPENER_DONE`，**不报错**。`0920G`/`0920H` 没出事不是更用心，是它们的判据落成了 pytest（有消费者）。

本条给完成判据装消费者：**泳道自报 `OPENER_DONE` 不算数，机器跑一遍判据才算数。**

## 一、A 部分：`docs/openers/run-lanes.sh` 加闸

在判状态那段（现有 `BUDGET-HIT`／`FAIL`／`OK`／`PARTIAL`／`CTX-RELAY`／`NO-SENTINEL` 之后、写 `results.tsv` 之前）插入机器判据闸：

1. **取判据**：按条目 id glob `docs/openers/<id>-*.md`。
   匹配数 ≠ 1 ⇒ **视为无判据，维持现状不拦**（向后兼容，⛔ 不许把老 opener 拦下来）。
   匹配唯一 ⇒ 从中提取 `## 机器判据` 标题之后的**第一个 ` ```bash ` 围栏块**。没有该节或没有 bash 块 ⇒ 同样维持现状不拦。
2. **安全预检**（🔴 必做，先于执行）：块内命中下列任一即**不执行**，状态记 `GATE-UNSAFE`，与 `FAIL` 同处置——
   `git push`、`git commit`、`git reset`、`git clean`、`rm -rf`、`sudo`、`curl`、`wget`、`ssh`、`scp`、`launchctl`、`> /dev/sd`、`mkfs`、反引号或 `$(` 里再套 `rm`。
   判据块的本分是**只读核验**，⛔ 不许有副作用。
3. **执行**：写进本批 `LOGDIR/gate-<id>.sh`，在**仓库根**跑（worktree 条收口时已 ff-only 合回并清 worktree，验的就是合入后的主工作区），`timeout 60`。
   - 退出码 0 ⇒ 状态**维持**原判（`OK` 仍是 `OK`）
   - 退出码非 0 或超时 ⇒ 状态改为 **`GATE-FAIL`**，并把判据块的 stdout/stderr 末 30 行追加进该条日志
4. **`GATE-FAIL`／`GATE-UNSAFE` 的处置 ＝ 与 `FAIL` 完全一致**：⛔ 不 `mark_done`（泳道标注不许摘）、**停本泳道**（后续条不跑）。
   理由：后续条会跑在未验收的产出上，比停下来代价大。
5. `results.tsv` 第 3 列照常写新状态（列数仍 13，⛔ 不再加列）。收工汇总多打一行：
   `🚦 机器判据：N 条过 / M 条不过（<不过的 id 列表>）`；一条判据块都没有时打 `🚦 本批无机器判据块`。

## 二、B 部分：`.claude/skills/kickoff/SKILL.md` 补写法

在「各阶段的必备内容 → 通用」附近加一小节（**≤15 行**，⛔ 不许扩写，该文件刚瘦到 26 KB）：

- 每份 opener **应当**有 `## 机器判据` 节，内含一个 ` ```bash ` 块
- 块以**退出码**为准：全过 `exit 0`，任一不符 `exit 1`（写法示例给一条 `[ "$(grep -c X f)" -ge 1 ] || { echo "X 缺失"; exit 1; }`）
- 🔴 判据块**只读、无副作用**：⛔ 不许 `git push/commit/reset/clean`、`rm -rf`、`sudo`、`curl/wget/ssh`——命中即 `GATE-UNSAFE`，与失败同处置
- 没有该节的 opener 不拦（向后兼容），但**新写的 opener 一律要有**
- 泳道自报 `OPENER_DONE` 不算数：`run-lanes.sh` 收工会自己跑一遍，不过即 `GATE-FAIL` 并停本泳道

## 五、机器判据

```bash
set -u
fail=0
chk() { if ! eval "$1"; then echo "✗ $2"; fail=1; else echo "✓ $2"; fi }
R=docs/openers/run-lanes.sh
K=.claude/skills/kickoff/SKILL.md
T=tests/test_run_lanes_gate.py
chk '[ "$(grep -c "GATE-FAIL" '"$R"')" -ge 2 ]'      "run-lanes.sh 有 GATE-FAIL"
chk '[ "$(grep -c "GATE-UNSAFE" '"$R"')" -ge 2 ]'    "run-lanes.sh 有 GATE-UNSAFE"
chk '[ "$(grep -c "机器判据" '"$R"')" -ge 1 ]'        "run-lanes.sh 认 ## 机器判据 节"
chk '[ "$(grep -c "机器判据" '"$K"')" -ge 1 ]'        "kickoff 补了写法"
chk '[ "$(wc -c < '"$K"')" -le 29696 ]'              "kickoff ≤29KB（未借机扩写）"
chk '[ -f '"$T"' ]'                                   "测试文件存在"
chk 'bash -n '"$R"                                    "run-lanes.sh 语法通过"
chk '[ "$(awk -F"\t" "NR==1{print NF}" .claude/handoff/lanes-20260920-141114/results.tsv)" = 13 ]' "results.tsv 仍 13 列"
exit $fail
```
