## 一、启动（后台常驻，不随本 CC 会话退出而结束）

1. 确认 `venv/bin/python` 存在、`app/web/server.py::create_app` 可导入（`venv/bin/python -c "from app.web.server import create_app; create_app()"` 不报错）
2. 端口选 `8096`（区别于 `.51` 的 `8095`，避免混淆）；若已被占用（`lsof -i :8096` 有输出），改用 `8097`，实际用的端口要在收工报告里写清楚
3. `nohup venv/bin/python -m uvicorn app.web.server:create_app --factory --port 8096 --host 127.0.0.1 > /tmp/hr-local-preview.log 2>&1 & disown`，把 PID 写进 `.claude/local-preview.pid`（内容just是数字，方便以后 `kill $(cat .claude/local-preview.pid)` 停掉）
4. 等 2 秒，`curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:8096/` 确认 `200`；再 `curl -s http://127.0.0.1:8096/api/jobs` 确认返回合法 JSON（用的是仓库自带的 `data/demo.db`，如果没有会在启动时自动建空库，那 `jobs` 数组可能是空的，属正常）
5. 任一步失败（导入报错/端口起不来/curl 不通）⇒ 停，把 `/tmp/hr-local-preview.log` 的报错原样贴出来，不要猜着改代码
