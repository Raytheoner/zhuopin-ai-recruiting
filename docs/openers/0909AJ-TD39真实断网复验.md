【三、第二段·自动断网脚本】🔴 **关网前必须先把三件事都写进脚本**：独立兜底、trap 恢复、采样循环。
写 `/tmp/aj/outage.sh` 并**后台**跑（⛔ 前台跑会连 CC 自己一起卡住）：

```bash
#!/bin/bash
DEV=en1                       # ⚠️ 改成第一节第 5 步实测出来的设备名
REPO=/Users/paulshao/Projects/HumanResource
LOG=/tmp/aj/samples.log
# ① 独立兜底：本脚本即使被 SIGKILL（trap 不执行）也能把网开回来。
#    900 秒 > 本脚本总时长（约 500 秒），⛔ 不许调到比总时长短——那会在测到一半时把网开回来。
( sleep 900; networksetup -setairportpower "$DEV" on ) >/dev/null 2>&1 &
disown
# ② trap 恢复：正常退出/中断都恢复
restore() { networksetup -setairportpower "$DEV" on; echo "$(date '+%T') RESTORE-TRAP" >> "$LOG"; }
trap restore EXIT INT TERM
sample() {
  echo "=== $(date '+%T') phase=$1 ===" >> "$LOG"
  cat "$REPO/data/liaison/liveness.json" >> "$LOG" 2>&1; echo >> "$LOG"
  # ⚠️ 列名以 storage/schema.py 为准：started_at / recovered_at / closed_by / alerted_at。
  # ⛔ 没有 ended_at 这一列（0909AG 的脚本写错过，那条 select 是报错的）。
  sqlite3 "$REPO/data/liaison.db" \
    "select started_at,recovered_at,closed_by,alerted_at,detected_by from liaison_outage_window order by started_at;" >> "$LOG" 2>&1
  tail -4 /tmp/aj/stderr.txt >> "$LOG"
}
for i in $(seq 1 8);   do sample BEFORE;  sleep 2; done   # 断网前基线 ~16s
echo "$(date '+%T') >>> WIFI OFF" >> "$LOG"
networksetup -setairportpower "$DEV" off
for i in $(seq 1 120); do sample OUTAGE;  sleep 2; done   # 断网 ~240s（> 180s 阈值）
echo "$(date '+%T') >>> WIFI ON" >> "$LOG"
networksetup -setairportpower "$DEV" on
for i in $(seq 1 120); do sample RECOVER; sleep 2; done   # 复网 ~240s
echo "$(date '+%T') >>> DONE" >> "$LOG"
```

起法：`bash /tmp/aj/outage.sh > /tmp/aj/outage.out 2>&1 &`
**起完就不要再发任何工具调用**，等它跑完（约 8.5 分钟）——期间 CC 无网。
⚠️ 若 CC 在断网期间失联/报错，**⛔ 不要重跑脚本**（会二次断网）：网络回来后先
`grep DONE /tmp/aj/samples.log`，有 `DONE` 说明已跑完，直接读日志判读。
