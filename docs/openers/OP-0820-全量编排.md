## 二、并发协议（**每条 opener 内已逐字内嵌，此处备查**）

1. **只 `git add` 本条 opener 明确列出的路径。** ⛔ 禁止 `git add -A` / `git add .` / `git commit -a`。这是整套并行编排成立的唯一前提。
2. **`git status` 里出现别人的改动是正常的**——那是并行的另一条 opener 在干活。不要停下、不要问、不要顺手提交。
3. ⛔ 不要在 commit 前 pull（并发下会被别人的未提交改动挡住）；push 被拒才 `git pull --rebase --autostash origin main` 重试。
4. push 被拒（non-fast-forward）→ 再 `git pull --rebase origin main` 后重试，**最多 3 次**，仍失败停下贴错误。
5. 报 `.git/index.lock: File exists` → **等 5 秒重试，最多 5 次**。⛔ **绝不删除该锁文件**——那是另一个 session 正在用，删了会毁掉它的提交。
