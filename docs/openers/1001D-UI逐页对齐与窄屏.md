## 零、为什么

`1001C` 已把共用层 `app/web/static/app.css`（`09-UI-Design.md` §3 令牌＋§6 组件类）铺到 8 个页面，
但 §5「逐页对齐」只做了三页（resume_review／resume_list／upload），还有两处硬缺口：

1. **`index.html`（1014 行）仍带 10+ 处颜色字面量**（`#fff3cd/#ffe69c/#664d03/#0f5132/#d1e7dd/#58151c/#dc3545/#dee2e6`
   等），与 `app.css` 的 `.notice`／`.badge`／`.btn-*` 重复——同一控件在不同页会长得不一样（§1 事实 4）。
2. **三个面试页缺 `<meta name="viewport">`**（实测 0 命中）⇒ 候选人在手机上打开同意/邀约页会按桌面宽度缩放，
   而 `09-UI-Design.md` §8 明确要求候选人侧两页窄屏可用、§10 判据 4 要求 375px 无横向滚动。

Shao Peishen 2026-10-07 答 `1a`：继续做不受阻的 UI 收尾（逐页对齐＋候选人两页窄屏验收）。

## 二、交付物

1. **`app.css` 补齐**：
   - `.notice-success`（`#d1e7dd` 底／`#badbcc` 边／`#0f5132` 字）、`.notice-danger`（`#f8d7da` 底／`#f5c2c7` 边／`#58151c` 字）；
   - `@media (max-width: 480px)`：`.btn { width: 100%; }`、正文与容器左右内边距 12px、
     `.data-table { display: block; overflow-x: auto; }`（候选人/窄屏下表格不撑破）、
     `#raw-text` 类容器高度放宽；
   - `img, table { max-width: 100%; }` 收口。
2. **8 页对齐**：
   - 三个面试页加 `<meta name="viewport" content="width=device-width, initial-scale=1">`（放在 `<meta charset>` 之后）；
   - `index.html`：把提示条/徽标/按钮的颜色字面量换成 `class="notice"`／`notice-success`／`notice-danger`／`badge`／`btn*`，
     ⛔ 逐条保留原文案与 DOM 语义（只改 class 与删除对应重复内联规则）；
   - `resume_list.html`／`resume_review.html`／`login.html`／`upload.html`：AI 提示句/按钮/空态统一挂共用类。
3. **`tests/test_candidate_pages_narrow.py`（新）**，三条断言（字段名以既有测试风格为准）：
   ① 候选人两页（`interview_consent.html`／`interview_invite_issue.html`）含 viewport meta；
   ② 这三页的内联样式与 `app.css` 里**没有 >375px 的固定宽度**（正则扫 `width:Npx`／`min-width:Npx`）；
   ③ `app.css` 含 `@media (max-width: 480px)` 且块内给 `.btn` 全宽。
