## 零、为什么

Shao Peishen 2026-09-20 带来姐妹项目（Win 端）的实况：七条无头泳道上下文峰值 151k–244k，**全部越过 150k 转场线，无一条按规则收尾**；根因是那道守卫「是提醒型、没有消费者」，超了很久没人知道。

本项目核对下来，缺口**同族但更隐蔽**：

- `results.tsv` 写 12 列（lane／id／status／mins／log／model／cost／in／out／cache_read／cache_write／turns），**没有一列是上下文峰值**。今天 `0920E` 那行的 129,144 是 `cache_write`，不是峰值——峰值我们**根本没记过**。
- `scripts/hooks/context-guard.py` 挂在 `UserPromptSubmit`。无头泳道一辈子只有开场那一条 user prompt（此时上下文≈0）⇒ **运行中永远不可能触发**；而且它开头就写死 `if HR_HEADLESS_LANE: return 0`（0916K 的显式豁免）。

⇒ 我们不是「越线不收尾」，是「**越没越线都不知道**」。本条只做**可观测**，⛔ 不改任何泳道行为、⛔ 不加任何截断或中止。
