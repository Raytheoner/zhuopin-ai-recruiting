## 二、接线判据（工程铁律 1 是硬约束，逐条对）

1. **只对群帧回推**：私信帧⛔ 不回推；群帧附件忽略口径（2026-09-21 定）不变。
2. **入队成功之后**才回推（先落库、后通知，⛔ 不许反过来）。
3. 回推是**独立 effect 节点**：复用 `notify/store.py` 既有的 `effect_send_group_notify` 与幂等键形状
   `{thread_id}:effect_send_group_notify:{摘要}`，⛔ 不另造一套幂等；effect 记录与业务写**同一连接、
   同一事务**（铁律 1），且该连接上不得出现第二个事务管理者。
4. **webhook 未配置 / 发送被拒** ⇒ 按 `load_group_webhook` 既有语义**拒发**并把门面记成 `rejected`
   ＋告警，⛔ 不许把值守线程打死、⛔ 不许静默当成功。
5. 限流与退避复用既有 `TokenBucket`／`effect_deliver_with_backoff`（⛔ 不新造重试机制）。
6. 回推文案走既有 `send_markdown` 通道，内容是**任务摘要**（⛔ 不含真实简历内容、⛔ 不含凭据，
   ⛔ 不把 webhook 地址写进日志或测试夹具——夹具用 `conftest.py` 里既有的 `example.invalid` 占位）。
