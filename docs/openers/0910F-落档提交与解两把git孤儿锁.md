【一、解两把 `.git` 孤儿锁】

判据真源＝`docs/findings/2026-08-26-index-lock-孤儿锁判据.md` §3（三项同时成立才可删）＋ §5（VM 场景补充判据）。
本节把三项完整抄在下面，⛔ 不要凭记忆做。

**两把锁的已知身份（Cowork·0909AU 于 2026-09-10 13:4x–13:5x 实测）**：

| 锁 | 大小 | mtime（CST） | 来源 |
|---|---|---|---|
| `.git/ORIG_HEAD.lock` | 0 字节 | 2026-09-10 **07:54** | `[Mac]0909AS` 合回 `main` 时撞上，分类器不放行删锁，交人 |
| `.git/index.lock` | 0 字节 | 2026-09-10 **13:52** | **Cowork·0909AU 自己的 `git status`**：git 新建它后 `unlink` 被拒（`warning: unable to unlink …/.git/index.lock: Operation not permitted`），锁就此留下 |

**逐把执行下面四步。⛔ 两把分开判、分开删，不许因为「顺手」就一起删。**

1. **判据 1 —— 文件 0 字节**：`ls -l .git/<锁名>`
   *为什么*：git 写 index 时会先往 lock 里写内容再 rename。0 字节＝创建了但一个字节都没写，基本排除「正写到一半」。
2. **判据 2 —— mtime 距今 > 10 分钟**：`stat -f '%Sm %z' .git/<锁名>`（macOS 用 `-f`，⛔ 别抄 Linux 的 `-c`）
   *为什么*：正常提交持锁是毫秒~秒级；10 分钟是给大仓库 `git add` 的极宽裕余量。
3. **判据 3 —— 无 git 进程，且 `.git` 下无写 FD**：
   ```
   pgrep -x git || echo NO-GIT
   lsof +D .git 2>/dev/null | grep -v ' r ' || echo NO-WRITE-FD
   ```
   🔴 **必须 `pgrep -x git`（精确匹配进程名），⛔ 绝对不要 `pgrep -f git`**——实测宿主机上 `-f` 命中 9 个微信 WebView 子进程（命令行里的 `Di·git·alGoodsApi` 含 `git` 三字母），会让本判据恒不成立、形同虚设。
   🔴 **只读 FD（`r`）不算持有者**，只有写模式（`u` / `w`）才说明可能在写。
4. **VM 补充判据 —— 本次已由 Cowork 侧闭掉，⛔ 不要卡在这一步**：
   判据 3 对 VM 内部的 git 是盲的（宿主机 `ps` 看不见 VM 内进程）。真源 §5 给的补丁是看 `PPID`：
   ```
   ps -eo pid,ppid,lstart,comm | grep -i Virtualization | grep -v grep
   ```
   `PPID = 1` ⇒ VM 已失去监管、可删；`PPID ≠ 1` ⇒ VM 还活着、**按真源不许删**。
   ⚠️ **本次大概率是 `PPID ≠ 1`**（那个 Cowork 接力 session 可能还开着），
   但真源 §5 末句写明：这种「VM 活着但 VM 内 git 已死」的形态**本判据给不出结论，只能进 VM 里查或问人**。
   ✅ **已进 VM 里查过**，Cowork·0909AU 2026-09-10 13:5x 在该 VM 内实测四条，全部指向「VM 内无任何 git」：
   - `pgrep -x git` → **空（exit 1）**
   - `ps -eo pid,ppid,comm | grep -i git` → **无任何命中**（连误报都没有）
   - 扫 `/proc/*/fd/` 找指向这两把锁的文件描述符 → **一个都没有**
   - 该 VM 内进程总数 **7 个**：`bwrap`／`bash`／`socat`×2／`bash` ＋ 采样时的 `ps`/`head`，是个干净的 shell VM
   ⇒ **VM 侧那一半已闭**：`PPID ≠ 1` 在本次只说明「Cowork 会话还开着」，**不说明 VM 内有活着的 git**。
   你只需把宿主机的判据 1/2/3 核过即可。

**决策**：某把锁的判据 1、2、3 **全中** ⇒ `rm -f .git/<锁名>`。
**任一不中 ⇒ 停下报**，把该锁的四步原始输出逐条贴进报告，⛔ 不删、⛔ 不猜、⛔ 不重试。
