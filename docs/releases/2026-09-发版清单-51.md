### 3.3 tasks 1.1：`.51` 同款 Windows 冒烟 `scripts.smoke_m2_deps`

脚本只 `import`、不下载模型。**在生产 `.venv` 里跑没有意义**（M2 依赖一个都没装，只会全 ❌），而把 `requirements-m2-u0.txt` 装进生产 `.venv` 会把 torch 等 ~1 GB 依赖塞进服务进程的环境——⛔ 不做。

```

# 2) .51 上建隔离 venv 并装轻依赖（六项 cp314 win_amd64 wheel 已在 requirements-m2-u0.txt 头注释里实测）
ssh zp51 "powershell -NoProfile -Command \"cd C:\apps\m2-smoke; C:\apps\zhuopin-recruit-agent\.venv\Scripts\python.exe -m venv .venv; .venv\Scripts\python.exe -m pip install numpy==2.5.3 pypdf==6.19.0 python-docx==1.2.0 reportlab==5.0.1 pillow==12.3.0 pymupdf==1.28.2 2>&1 | Select-Object -Last 3\""
# 3) 重依赖逐项试装（各自独立，失败不影响别的；输出贴进 docs/m2-model-comparison.md「.51 同款 Windows」节）
ssh zp51 "powershell -NoProfile -Command \"cd C:\apps\m2-smoke; .venv\Scripts\python.exe -m pip install paddlepaddle==3.4.0 2>&1 | Select-Object -Last 2; .venv\Scripts\python.exe -m pip install paddleocr==3.7.0 2>&1 | Select-Object -Last 2; .venv\Scripts\python.exe -m pip install FlagEmbedding==1.4.2 2>&1 | Select-Object -Last 2\""
```
