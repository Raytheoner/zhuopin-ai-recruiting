# 招聘 AI 小助手 · 试用 + 反馈（3-5 分钟）

> 这份文档给业务经理直接看，从头看到尾照做就行。发给经理前，请**先看文档最底部"发送前必填"那一段**——里面有两处需要陪同人员/Paul 提前填好，不能空着直接发。

## 这是什么

你输入一句话的用人需求，AI 会问你几个问题，然后帮你整理出岗位要求、生成一份岗位描述（JD）。现在是内部试用阶段，**不涉及任何候选人信息**，随便试。

## 怎么用

1. 打开链接：`http://192.168.100.51:8095/hr/recruit-agent/`（需要门户口令，找 Paul / IT 要）
2. 用一句话描述一个你最近真实招过或正在招的岗位，比如："要招一个做 AUTOSAR 的嵌入式软件工程师"
3. AI 会追问几个问题（最多 5 轮），正常回答就行，不确定的可以说"不确定"或"暂时没有"
4. 看一下 AI 整理出来的岗位要求对不对
5. 看一下生成的岗位描述（JD）
6. 往下翻，用 3 分钟回答几道勾选题——**不用打字，能勾就不写字**
