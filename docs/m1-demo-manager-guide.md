# 招聘 AI 小助手 · 试用 + 反馈（3-5 分钟）

> 这份文档给业务经理直接看，从头看到尾照做就行。发给经理前，请**先看文档最底部"发送前必填"那一段**——里面有三条要陪同人员/Shao Peishen 经手的事（第 2 题的截图、门户口令、客观信息回填），不能空着直接发。

## 这是什么

你输入一句话的用人需求，AI 会问你几个问题，然后帮你整理出岗位要求、生成一份岗位描述（JD）。现在是内部试用阶段，**不涉及任何候选人信息**，随便试。

## 怎么用

1. 打开链接：`http://192.168.100.51:8095/hr/recruit-agent/`（需要门户口令，找 Shao Peishen / IT 要）
2. 用一句话描述一个你最近真实招过或正在招的岗位，比如："要招一个做 AUTOSAR 的嵌入式软件工程师"
3. AI 会追问几个问题（最多 5 轮），正常回答就行，不确定的可以说"不确定"或"暂时没有"
4. 🔴 **追问结束、屏幕上出现"确认画像"这一页时，先别点确认、也先别往下看 JD——把这一页整页截图存下来。**
   这张图第 2 题要用。**这一步一旦跳过就补不回来了**：点了确认再回头截，看到的已经是 JD，不是这一页。
   - **这一页长什么样**：一条一条的**岗位要求清单**（人数、学历、经验年限、核心技能……），一行一项，
     旁边有"确认"按钮，可能还有一块"以下字段未指定"的提示。
   - **它不是 JD。** JD 是点了确认之后才生成的一大段**成文招聘文案**（有"岗位职责""任职要求"这种小标题、
     句子连成段）。⚠️ 前两位试用的经理都截成了 JD，第 2 题因此白填了——**看到成段文案就是截错了，退回上一页重截。**
5. 看一下 AI 整理出来的岗位要求对不对
6. 点确认，看一下生成的岗位描述（JD）
7. 往下翻，用 3 分钟回答几道勾选题——**不用打字，能勾就不写字**（第 2 题要用第 4 步存的那张截图）
