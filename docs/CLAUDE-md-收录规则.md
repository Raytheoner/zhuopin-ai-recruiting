## CLAUDE.md 收录规则（防膨胀）

本文件是每会话自动加载的**约束层**，不是项目档案。规则语料只增不减会稀释所有既有规则的注意力份额——企业AI转型 2026-08-09 实测：顶部进度流水账一度占全文 49%，把真正的规则挤到注意力边缘。改本文件前先过一遍下面三关。

**关一：只有这四类能进正文**，其余一律写进编号文档，正文最多留一行指针。

1. 违反了会立刻出错、且下游测试/review 都兜不住的硬约束——工程铁律、合规红线、部署约束、决策代理
2. 路由指针：哪件事看哪份文档，一行一条
3. 给 Paul 的指令强制格式与固定判据
4. 目录级读写权限、称呼与沟通约定

**关二：这几类一律不进正文**，即使内容本身很重要。

| 内容 | 去处 |
|---|---|
| 进度、状态、已完成/待办、里程碑流水账 | `07-开发环境现状与优化待办.md` / 变更包 `tasks.md` |
| 调研过程、选型论证、"为什么不选 B" | `01` / `06` |
| 操作步骤、命令行、发版流程 | `05-发布运行手册.md` |
| 已踩过的坑与症状 | `07` 第三节 |
| 某条规则超过 5 行的展开说明 | 独立文档，正文只留结论 |

**关三：三条量化红线，任一条触发即拆。** 拆＝把超出部分挪进编号文档，正文留结论 + 一行指针。

1. 全文 > **250 行**
2. 任一 `##` 小节 > **40 行**
3. 任一条规则的正文 > **5 行**

新增内容前自问一句：**"没有这条，下一个会话会立刻做错什么？"** 答不出具体错误就不进正文。
