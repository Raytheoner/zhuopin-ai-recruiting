## 一、为什么

Cowork 的 bash 在隔离 VM 里，碰 `.git/` 只能写不能删，连只读的 `git status` 都会留下删不掉的 `index.lock`（CLAUDE.md「git 相关只能在 CC」，2026-09-10 实证两把锁）。于是它写的文档必须等「下一条泳道顺带提交」，已多次造成：

- 未提交态滞留（Cowork 写完就转场，文档在工作区里悬着）
- ff 合并被挡（09-17 `0917K`：泳道分支要 ff 进 main，main 工作区里有 Cowork 的未提交改动）

发车已有一条**不经分类器**的路：`.claude/handoff/launch/<ts>.request` → launchd WatchPaths → `docs/openers/lane-launcher.sh`（`0909G`，见 `.claude/skills/lane-dispatch/SKILL.md`「发车怎么起」）。本条照样做一遍，只是动作换成 git 提交：**起进程的不是 Claude、也不是 Cowork 的 VM，是操作系统，以 Shao Peishen 本人的身份在宿主机上跑 git。**

## 二、设计

### 三个文件

| 文件 | 角色 |
|---|---|
| `scripts/commit_request.py` | 全部逻辑：认领 → 解析 → 白名单 → diff 核对 → 体积闸 → 等锁 → add/commit → push → 写结果文件 |
| `docs/openers/commit-launcher.sh` | 薄壳：找 python（`venv/` 优先）、cd 仓库根、exec 上面的脚本。launchd 用 `/bin/bash` 起它 |
| `scripts/install_commit_launcher.py` | 幂等安装器：生成 plist 并 bootstrap；`--print` 只打印不装 |

**为什么 Python ＋ 薄壳而不是纯 bash**：请求是 JSON、要做路径白名单与逐条校验、要解析 `git status -z` 的 NUL 分隔输出（中文文件名不带 `-z` 会被 git 加引号转义成 `\346\216\245…`），这些在 macOS 自带的 bash 3.2 里没有 jq 都得手写解析器，且 UTF-8 locale 下静默出错（run-lanes.sh「locale 钉死」）。Python 标准库全都有，闸门函数可以直接 import 进 pytest 断言。

### 协议（Cowork 侧）

1. 用 **Write 工具**写 `.claude/handoff/commit/<时间戳>.request`，内容一个 JSON 对象：
   ```json
   {"message": "docs(liaison): …", "paths": ["docs/findings/x.md", "openspec/changes/<名>/tasks.md"], "push": true}
   ```
   `paths` 只能是**文件**（不是目录、不带通配），相对仓库根；`push` 省略即 false。
2. 等 `<同名>.done`（JSON，含 `commit` hash、`branch`、`pushed`、`doc_size_test`）／`.rejected`（含 `reason`）／`.deferred`（index.lock 在用）。
3. `.deferred` **不会自动重试**（与 lane-launcher 同理：改回 `.request` 会自触发空转）——要重发就写一个新的 `.request`。

### 路径白名单（机器闸）

| 判定 | 规则 |
|---|---|
| 允许 | `docs/**`（排除 `docs/openers/run-lanes.sh`、`lane-launcher.sh`、`commit-launcher.sh`）；`openspec/changes/<名>/tasks.md` |
| 拒绝 | `tools/` `app/` `scripts/` `tests/` `.claude/` `CLAUDE.md` `data/` `.env*`；含 `..`；绝对路径；`-A`／`.`／任何以 `-` 开头；目录；通配；`./` 或 `//` 未规范化；**不在工作区 diff 里的路径** |

列表里混一个非法的就整条拒绝，⛔ 不做「跳过这个继续」——半截提交比不提交更难收拾。

### 并发协议（与 CLAUDE.md 四条逐一对应）

1. 只 `git add -- <逐个路径>`；commit 用 `git commit --only -- <路径>`，**别的 session 已暂存的内容原样留在暂存区、不进这个 commit**（测试 ① 断言）
2. `git status` 里别人的改动不管
3. ⛔ commit 前不 pull；push 被拒才 `git pull --rebase --autostash origin <当前分支>` 后重试，≤ 3 次；rebase 失败立即 `--abort`，⛔ 不把仓库留在 rebase 中
4. `index.lock` 存在 ⇒ 等 5 秒 × 5，仍在 ⇒ `.deferred`，⛔ **绝不删锁**（测试 ④ 断言锁原样在）

### 体积闸

提交前跑 `tests/test_doc_size_budget.py`：`venv/bin/python` 优先（`.venv/` 兜底），都没有则用当前解释器（若有 pytest），否则跳过并在 `.done` 的 `doc_size_test` 字段注明。红 ⇒ `.rejected`，不 add、不 commit。

### plist 两项必带

`AbandonProcessGroup: true` ＋ `EnvironmentVariables.PATH`（绝对路径、含 `~/.local/bin` 展开值与 `/opt/homebrew/bin`）——09-09 `0909Y` lane-launcher 实证缺这两项会被连坐杀／找不到命令。测试钉住。

## 三、测试

`tests/test_commit_launcher.py`，72 条（含参数化），在 tmp git 仓里走真正的薄壳：

- ① 合法请求 ⇒ commit 只含列出路径；未列出的改动与别人暂存的改动都没进来
- ② 白名单外／`..`／绝对／`-A`／`.`／目录／通配 ⇒ rejected 且无 commit、无暂存（19 种）
- ③ 未改动路径 ⇒ rejected
- ④ index.lock ⇒ deferred 且锁未删
- ⑤ push=false 不推 ／ ⑥ push=true 推到 bare origin
- ⑦ 体积闸红 ⇒ rejected 不 commit；无测试文件 ⇒ `.done` 注明跳过
- 畸形 JSON 7 种 ⇒ rejected；一次只处理最早一个；空转无副作用
- `validate_path` 纯函数 4 正 27 反
- plist：AbandonProcessGroup、PATH 绝对、触发契约、纯函数、`--print` 不落盘

真仓库只读冒烟：对 `/Users/paulshao/Projects/HumanResource` 跑 `changed_paths`（中文路径正确）、`index_lock_path`（worktree 下正确解析到 `.git/worktrees/<名>/index.lock`）、`run_doc_size_test`（`venv/bin/python` 5 passed）。
