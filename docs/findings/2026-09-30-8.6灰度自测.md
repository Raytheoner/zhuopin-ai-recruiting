## 恒等不变式

> 判据出处：`CLAUDE.md` 工程铁律 1 的 reviewer 判据——
> 每个 `effect_*` 节点的 `effect_log` 条数与其业务表行数**按 thread 恒等**。
> 比对口径逐字取生产映射 `tools/liaison/storage/effects.py::EFFECT_NODE_TO_TABLE`
> 与 `tools/liaison/retention.py::RETENTION_DELETE_NODE`（留存清理可解释的差额要补回等式右边），
> 与 `tools/liaison/tests/test_liaison_effects.py::assert_effect_log_identity` 的算法一致。

### 原始命令

```bash

"$MAIN/venv/bin/python" - <<'PY'
import sqlite3, pathlib, json

from tools.liaison.retention import RETENTION_DELETE_NODE

    eff = dict(conn.execute("SELECT thread_id, COUNT(*) FROM effect_log WHERE node_name=? GROUP BY thread_id", (node_name,)))
    biz = dict(conn.execute(f"SELECT thread_id, COUNT(*) FROM {table} GROUP BY thread_id"))
    cleaned = dict(conn.execute(
        "SELECT e.thread_id, COUNT(*) FROM effect_log AS e WHERE e.node_name=? AND EXISTS("
        "SELECT 1 FROM effect_log AS d WHERE d.node_name=? AND d.thread_id=e.thread_id "

        equal, unequal = (equal+1, unequal) if actual == expected else (equal, unequal+1)
print(f"合计：相等 {equal} 组 / 不等 {unequal} 组")
```
