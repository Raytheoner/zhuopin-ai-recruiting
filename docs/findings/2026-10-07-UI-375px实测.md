## 五、静态证据链：候选人两页主按钮**非全宽**（本泳道只登记，⛔ 不改代码）

证据（可复现，均为逐字 grep 结果）：

1. 两页 `class="btn"` 命中数 **都是 0**：
   `grep -c 'class="btn' app/web/static/interview_consent.html app/web/static/interview_invite_issue.html` → `0` / `0`
2. 两页的按钮（5 个，全是裸 `<button>`）：

   | 文件 | 行 | 按钮 |
   |---|---|---|
   | `interview_consent.html` | 28 | `<button id="submit-consent-btn">提交</button>` |
   | `interview_consent.html` | 35 | `<button id="request-code-btn">请求验证码</button>` |
   | `interview_consent.html` | 39 | `<button id="verify-btn">提交验证码</button>` |
   | `interview_invite_issue.html` | 30 | `<button type="submit">签发</button>` |
   | `interview_invite_issue.html` | 36 | `<button id="code-btn" disabled>查看验证码</button>` |

3. `app.css` 里**唯一**把按钮拉成全宽的地方，是窄屏媒体查询里的 `.btn`（第 143–146 行）：

   ```css
   @media (max-width: 480px) {
     .btn { width: 100%; }
     ...
   }
   ```

   全文另有一处 `width: 100%`，在第 59 行，是 `.data-table`，与按钮无关。
4. 两页自己的内联样式里**没有**任何按钮宽度规则：`interview_consent.html` 只有
   `.actions button { margin-right: 8px; }`，`interview_invite_issue.html` 只有
   `label { display: inline-block; min-width: 100px; }`。

⇒ 这 5 个按钮在 375px 下拿到的宽度是浏览器默认的 shrink-to-fit（UA 默认内边距约 `1px 6px` + 2–4 个汉字），
必然**远小于 300px**。这条结论是 CSS 层面的确定性推断（**不是**浏览器实测值），足以判定本 opener 的
判据「按钮宽度 ≥ 300」在**当前页面上必不过**。

逐条登记（「页面／元素／实测值／建议修法」；实测值一列因沙箱留步，填的是静态推断并标了出处）：

| 页面 | 元素 | 实测值 | 建议修法 |
|---|---|---|---|
| `interview_consent.html` | `#submit-consent-btn`（提交） | ⏸ 未取到（§五 静态推断 < 300px） | 见下方「修法」 |
| `interview_consent.html` | `#request-code-btn`（请求验证码） | ⏸ 未取到（同上） | 同上 |
| `interview_consent.html` | `#verify-btn`（提交验证码） | ⏸ 未取到（同上） | 同上 |
| `interview_invite_issue.html` | `form#issue-form button[type=submit]`（签发） | ⏸ 未取到（同上） | 同上 |
| `interview_invite_issue.html` | `#code-btn`（查看验证码） | ⏸ 未取到（同上） | 同上 |

**修法（推荐一种，⛔ 本泳道不动手）**：在 `app.css` 的 `@media (max-width: 480px)` 块里，把候选人两页的按钮
一并纳入全宽规则（`.actions button, #issue-form button, #code-btn { width: 100%; }` 形态，选择器怎么写可再收敛）。
⚠️ 不建议直接给这 5 个按钮挂 `class="btn"`：`.btn` 带 `font-size: 14px`，而 `09-UI-Design.md` §8 对候选人侧
要求「字号 ≥16px 防缩放」——挂类反而把字号从默认 16px 降下去；真要挂类，就得同处把字号提回 16px。
